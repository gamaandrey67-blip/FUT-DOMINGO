Como funciona

1. Cadastre os jogadores e defina suas estrelas.
2. Selecione quem vai jogar.
3. Sorteie os times buscando equilíbrio (ou use uma série para manter os times).
4. Registre cada gol, seu autor e a assistência.
5. Consulte o histórico e as estatísticas por período. Toque no nome de um jogador para ver o perfil. O app também guarda partidas offline para sincronizar depois.

Montar os times

Como montar os times?

Sorteio normal: nova divisão a cada partida. Modo SÉRIE: os mesmos times durante um período. Repetir último time: reaproveita a formação da última partida salva.

Série

Ajuste pelo calendário se precisar.

Selecione os jogadores da série na lista abaixo, sorteie e confirme. Os times ficarão fixos até o administrador decidir sortear de novo.

Quem vai jogar?

O sorteio procura dividir os jogadores de forma equilibrada pelas estrelas. Com quantidade ímpar, um time ficará com um jogador a mais.
